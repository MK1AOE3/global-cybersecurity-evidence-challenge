Preservation Rules

1. Administrative records appear at the top of each file, outside the original response.
2. Original responses are preserved verbatim after the administrative separator.
3. Reviewer analysis belongs in `reviews/`, not inside a submission.
4. Model-reported versions and timestamps are not treated as independently verified.
5. Corrections to attribution or metadata are dated and recorded without rewriting history.
6. Agreement between responses is convergence of framing, not independent security validation.

Scope

This index covers responses to the controlled MKM-GCEC-001 prompt. Earlier free-form or exploratory question sets are not presented as controlled submissions to that prompt.

The unchanged prompt is available at [PROMPT.md](../PROMPT.md). Reviewer analysis is available at [reviews/model-comparison.md](../reviews/model-comparison.md).
